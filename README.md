This file contains the development process of my initial DevOps project.

Created a linux CentOS VM and enabled SSH.
SSH'ed from my local environment to the VM using Putty.
Created my project directory and installed Python, Git and UFW.
Installed Pip, then using the pip command pulled flask and created a venv.
Created a simple app.py script containing very simple code just to try it out.
Currently to run the app all you need to do is start the app.py file using python.
